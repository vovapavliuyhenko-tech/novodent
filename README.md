# Emily Clinic — сайт стоматологии

Одностраничный сайт стоматологии Emily Clinic (Новороссийск, просп. Дзержинского, 194).

- `index.html`, `styles.css`, `script.js` — главная страница
- `opal3d.js` — 3D-фигуры из перламутрового стекла (three.js, загружается с CDN)
- `common.js` — шапка, мобильное меню, баннер cookie
- `privacy.html`, `offer.html`, `cookies.html` — юридические документы (шаблоны: заполните реквизиты)
- `img/`, `video/` — изображения и видео

## Локальный запуск

```bash
node server.js
```

Сайт откроется на http://localhost:5500. Зависимостей нет.
